# OrgKit feedback

Report problems and request features for [OrgKit](https://orgkit.dev): the website tools
and the [Chrome extension](https://chromewebstore.google.com/detail/ankhhhoiodgbnjellnmmgcecfecagabe).

- **Something broke or looks wrong:** [Report a problem](../../issues/new?template=problem.yml)
- **Something is missing:** [Request a feature](../../issues/new?template=feature.yml)
- **Ideas and questions:** [Discussions](../../discussions)

Before you open a new issue, search the [open issues](../../issues). If yours is there, add a 👍
reaction. Reactions decide what gets built next.

> **Posts here are public.** Do not paste org names, record data, usernames, session IDs,
> screenshots that show customer data, or anything from a client org.

Found a security issue? Do not post it here. See [how to report it privately](https://orgkit.dev/trust/#contact).

OrgKit is an independent project and is not affiliated with or endorsed by Salesforce, Inc.
